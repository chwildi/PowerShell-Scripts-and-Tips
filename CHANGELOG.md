## Changelog rules

For future changes use these headings when applicable:

- `Added` — new scripts, modules, functions or documentation
- `Changed` — behavior or configuration changes
- `Fixed` — bug fixes
- `Security` — security-relevant improvements
- `Deprecated` — features/scripts planned for removal
- `Removed` — removed functionality

Do not include customer names, internal domains, secrets, incident details or other confidential information in changelog entries.
